# Files that often come with HDF5 and NetCDF files

- Pickle Viewer (.pkl files): Opens Python pickle files without Python and never runs their code.
- Tensor Viewer (.npy, .safetensors or .gguf files): Shows NPY, NPZ, Safetensors and GGUF tensors with stats and heatmaps.

Each one is a separate free extension. Nothing installs on its own.
