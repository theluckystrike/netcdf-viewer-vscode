# Open a file

Click any `.nc`, `.nc4`, `.h5`, `.hdf5` or `.he5` file in the Explorer. It opens in HDF5 NetCDF Explorer.

If another editor opens instead, right-click the file and choose "Open in HDF5 NetCDF Explorer", or use "Reopen Editor With...".

The file is read in a background thread, by slice. A 40 GB file opens as fast as a 1 MB one.
